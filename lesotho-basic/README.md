# Visit Lesotho – Tourism Website

Web Design (DIWD2110) – Assignment 1

## Pages
- `index.html` – Home: blue hero, search box, popular destinations, travel tips
- `about.html` – History, culture, quick facts table
- `services.html` – Tours, accommodation and transport with filter buttons
- `gallery.html` – Photos with a popup (next / previous)
- `contact.html` – Booking form with cost calculator, contact form

Other files: `css/style.css` (my styles), `js/script.js` (my JavaScript), `images/`.

## How it meets the rubric
- **HTML5:** header, nav, main, section, article, aside, footer, address; lists, table, forms, alt text; input types email, tel, date, number, search.
- **CSS3:** external CSS, Google Font, colours, borders, padding, shadows, CSS Grid (gallery), Flexbox (navbar), hover effects, transitions, dark mode, media query.
- **Bootstrap 5:** container/row/col with md and lg breakpoints; navbar, cards, modal, accordion, alerts, buttons, badges, forms, table.
- **JavaScript (8 features):** dark/light mode, active menu link, search, filter, gallery popup with next/previous, cost calculator, booking form validation, contact form validation.
- **Advanced features:** localStorage (theme and visitor name for "Welcome back"), DOM manipulation, search and filtering, modal window.

## Demo steps
1. Type "sani" in the search box on Home.
2. Click **Dark**, then open another page – it stays dark.
3. Services: click the filter buttons.
4. Gallery: click a photo, then Previous / Next.
5. Contact: click **Book Now** empty to see errors, then fill it in and watch the total. After booking, go to Home to see "Welcome back".

## Hosting on GitHub Pages
Upload all files to a public GitHub repository, then Settings → Pages → Branch `main`, folder `/ (root)` → Save.
